# Template Reference

Templates are under `vault-template/00_System/Templates/`.

- `DailyNote.md`: daily summary + link index for sessions/dashboard/resources/thinking/articles/personallife
- `DailyPlan.md`: today's execution planning template
- `DashBoard.md`: system status dashboard template
- `Session.md`: single focused work record
- `Project.md`: project objective/scope/milestones
- `AGENTS-Project.md`: agent instructions per project
- `Log.md`: project development progress log for each agent collaboration session
- `Thinking.md`: evergreen insight draft
- `Article.md`: article draft and publishing metadata
- `Resource-Inbox.md`: unreviewed resource intake template
- `Resource-Library.md`: reviewed resource library template
- `Diet-Meal-Record.md`: personal diet meal logging template with macro/kcal table

All templates use placeholder variables like:
- `{{date}}`
- `{{updated}}`
- `{{project_name}}`
- `{{session_id}}`
- `{{topic}}`
- `{{source_url}}`
- `{{from_who}}`
- `{{resource_type}}`
